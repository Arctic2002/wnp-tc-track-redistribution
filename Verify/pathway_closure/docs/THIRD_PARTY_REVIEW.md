# 第三方审查与代码接入

## 1. 放置方式

每个第三方来源建立独立子目录：

```text
third_party/<reviewer_or_model_id>/
├─ SOURCE.md
├─ review.md
├─ code/
└─ results/
```

`SOURCE.md` 至少记录：

- 审查者、模型或机构名称；
- 审查日期和版本；
- 使用的输入文件及其哈希；
- 使用的软件环境；
- 是否看过本目录现有结果；
- 代码许可证或使用许可；
- 任何未公开提示词、人工干预或参数选择。

## 2. 可以比较的内容

- 分解公式是否逐格精确闭合；
- 路径权重是按点、按线段、按气旋还是按年份；
- 模型是在完整样本拟合后冻结，还是在各时期重新拟合；
- 类型数、路径重采样点数和网格大小；
- block bootstrap 的抽样单位；
- USA、JMA、CMA 是否使用原生位置和原生强度口径；
- 贡献比例采用投影、绝对范数还是总变差定义。

不同定义下的数值不能直接判定谁“复现失败”，应先统一 estimand。

## 3. 不接受的接入方式

- 不登记来源就覆盖 `src/` 或 `results/`；
- 根据结果显著性反复改变类别数、分期或阈值；
- 分别对前后期聚类后，把标签差异当作路径变化；
- 把月平均环流的一致性解释写成逐气旋动力归因；
- 只提供截图而不提供可核验数值或代码。
