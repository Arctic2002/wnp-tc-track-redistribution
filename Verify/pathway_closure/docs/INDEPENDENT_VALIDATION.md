# 独立验证标准

路径闭环分析的独立验证结果如下：

- 分解公式逐格精确闭合。
- 路径权重口径在结果表中明确区分按点、按线段、按气旋和按年份。
- 模型在完整样本上拟合一次，并在各时期比较中保持参数固定。
- 类型数、路径重采样点数和网格大小由配置明确记录。
- block bootstrap以年份为抽样单位。
- USA、JMA和CMA使用各自原生位置和原生强度口径。
- 贡献比例分别按投影、绝对范数或总变差定义，并只在相同estimand下比较。

不同定义下的数值只在 estimand 一致时比较。

## 解释边界

- 类别数、分期和阈值不随显著性结果改变。
- 前后期使用同一固定路径模型，标签差异不被当作路径变化。
- 月平均环流的一致性不解释为逐气旋动力归因。
- 所有图示均有对应的可核验数值和代码。

标签置换、相对生成点分解、k=2—7扫描、起始年/切点敏感性、域/分母敏感性和跨机构比较均已完成。
