# 反事实引导流轨迹试验：设计与预设判据

建立日期：2026-08-04
判据在计算前预设，计算后保持不变。

## 1. 动机

本试验使用可证伪的反事实检验，把生成点与引导流分别替换为前后两期的取值，
检验观测到的路径场差异能否由引导流变化产生。该试验不是全物理数值模式，
其估计对象是月平均引导流对气候态路径倾向的解释能力。

## 2. 数据与分析口径

| 项 | 取值 | 来源 |
|---|---|---|
| 轨迹 | `data/processed/tracks.csv`，6小时 | Core |
| 筛选 | `season∈[1966,2025]`、`wind≥34kt`、`nature∈{TS, NaN}` | `paper2_dynamic/28_spatial_redistribution.py` |
| 空间域 | `regions.tc` = 100–180°E, 0–40°N | `config/config.yaml` |
| 网格 | 2.5°（`grids.density_bin`），16×32 格 | 同上 |
| 相对密度 | 逐年 `histogram2d(lon,lat)` 后除以年总和，再按期平均 | `_annual_path_fields()` 点权重定义 |
| 分期 | P1 = 1966–1995，P2 = 1996–2025 | `PRIMARY_SPLIT = 1995` |
| 引导流 | `data/interim/steering.nc` 的 `u_steer`/`v_steer`，850–300 hPa 气压加权，**月均** | Core |

样本：合格轨迹点 31194，风暴 1550（P1 812 / P2 738）。域内寿命中位数 19 个 6 小时步。

## 3. 模型

beta 平流（BAM）：

```
c = α · V_steer(lat, lon, month, period) + V_beta
```

- `α` 与 `V_beta = (u_β, v_β)` 由**全期 1966–2025 观测位移**最小二乘标定一次，
  之后在所有情景中**固定不变**。
- 因此各情景之间**唯一的差别是引导流气候态与生成点集合**，不存在参数调节空间。
- 积分：6 小时步长，前向欧拉；步数取该种子风暴的观测域内寿命，保持寿命分布一致。
- 终止：离开 `regions.tc` 或达到寿命。
- 引导流取种子风暴生成月份对应的该期月气候态。

## 4. 四组情景

| 情景 | 生成点 | 引导流 | 用途 |
|---|---|---|---|
| `BASE_P1` | P1 观测 | P1 气候态 | 基准 |
| `BASE_P2` | P2 观测 | P2 气候态 | 与 `BASE_P1` 之差 = 模型可复现的**全效应** |
| `STEER` | P1 观测 | **P2** 气候态 | 与 `BASE_P1` 之差 = **纯引导流效应** |
| `GEN` | **P2** 观测 | P1 气候态 | 与 `BASE_P1` 之差 = **纯生成位置效应** |

对应关系：`STEER` 对应Shapley分解的生成后传播项，`GEN` 对应生成分布项。
这给出一条与 Shapley **相互独立**的验证路径。

## 5. 预设判据

记 `d_obs` = 观测 P2 − P1 相对密度差异场；`d_full`、`d_steer`、`d_gen` 为模型对应差异场。
所有相关系数在 16×32 = 512 个格点上计算。

### 判据 0（前置有效性门槛，**必须先过**）

**`r(d_full, d_obs) ≥ 0.30`**

若不满足，说明月均引导流驱动的 BAM 连"生成点＋引导流全换"都复现不了观测差异，
则模型不足以约束机制问题，`d_steer`不作物理解读。

### 判据 1（主判据，仅在判据 0 通过后适用）

**`r(d_steer, d_obs)`**

| 取值 | 判定 | 解释 |
|---|---|---|
| ≥ 0.40 | 引导流变化可实质复现观测路径重组 | 机制支持 |
| 0.20–0.40 | 部分复现 | 部分解释 |
| < 0.20 | 引导流变化不足以解释 | 不构成机制支持 |

### 判据 2（量级）

`TVD(d_steer) / TVD(d_obs)` —— 复现的差异幅度占观测的比例。仅作描述，不设阈值。

### 判据 3（与 Shapley 的独立交叉验证）

引导流份额 = `‖d_steer‖ / (‖d_steer‖ + ‖d_gen‖)`（L1 范数）。

Shapley分析给出生成后传播占73.7%—80.0%。若本试验份额落在**60%—90%**，
视为两条独立路径相互印证；显著偏离则视为两种估计对象之间的分歧。

## 6. 解释边界

- 月均引导流无法分辨单个气旋的天气尺度移动；结果表示气候态路径倾向，不表示单个风暴路径。
- BAM 不含强度演变、地形、陆面衰减与海气反馈。
- 未做位相内部变率（PDO/IPO）与外强迫的分离，本试验不承担归因到强迫的功能。
- 结论限定为"引导流气候态变化能否产生观测量级与形态的路径重组"，不等价于因果归因。
