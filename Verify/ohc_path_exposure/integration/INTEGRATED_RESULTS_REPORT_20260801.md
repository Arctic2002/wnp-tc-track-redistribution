# OHC300路径暴露整合结果报告

## 1. 可以得到的核心结果

现有数据支持一条可复现的新叙事：西北太平洋热带气旋的路径—季节暴露权重向较高纬度重新分配，使同期月尺度OHC300暴露出现负的重分配贡献；与此同时，海洋热场增暖产生稳定的正贡献。两个分量方向相反，净暴露变化是它们与年际共同变化项叠加后的结果，其区间多数跨0。

因此，结果说明“路径—季节重分配如何改变气旋所经海域的同期OHC暴露”，不支持“OHC导致路径北移”的动力归因，也不支持“净OHC暴露已经显著下降”。

## 2. 证据层级

### 2.1 最稳健：重分配项为负，海洋项为正

两个分期各含64个机构、路径定义、年份口径、海陆口径和权重组合：

- 128/128个组合的路径—季节重分配点估计为负；
- 128/128个组合的海洋热场变化点估计为正，且128/128个bootstrap区间完全大于0；
- 128/128个共同变化项点估计为负，其中98/128个区间完全小于0；
- 总暴露变化只有92/128个点估计为负，仅8/128个区间完全小于0，且这8个均来自1966年起比较。

共同变化项虽在大量组合中区间不跨0，但它只是“年均乘积”与“均值乘积”的代数差，不对应可识别的物理交互、反馈或动力机制。该边界必须与结果同时陈述。

### 2.2 完整时段证据强于1982年起时段

PRIMARY、`ts_only`、日历年、仅海洋源点和气旋归一—年份等权主口径结果如下；单位为`10⁸ J m⁻²`，括号为3年块bootstrap 95%区间。

| 比较 | 总暴露变化 | 路径—季节重分配项 | 海洋热场变化项 | 年际共同变化项 |
| --- | ---: | ---: | ---: | ---: |
| 1966—1995 vs 1996—2025 | −3.394（−9.483，2.501） | −6.951（−13.481，−0.616） | 4.211（2.745，5.604） | −0.655（−1.041，−0.189） |
| 1982—2003 vs 2004—2025 | −1.747（−9.290，5.690） | −5.324（−13.774，3.259） | 4.145（2.167，5.947） | −0.568（−1.008，−0.054） |

1966年起主口径的重分配区间不跨0；1982年起仍为负，但区间跨0。完整时段64个组合中25个重分配区间完全小于0，1982年起仅11个。因此可以说方向跨口径一致，但不能说卫星时期内重分配幅度已经得到同等强度的区间支持。

### 2.3 跨机构方向一致，但量级存在资料敏感性

四机构主口径的1966年起重分配点估计为：CMA −5.227、JMA −5.813、PRIMARY −6.951、USA −5.245；1982年起分别为−6.948、−3.766、−5.324和−3.663，单位均为`10⁸ J m⁻²`。四机构方向一致，但完整时段只有PRIMARY区间不跨0，1982年起四机构区间均跨0。

相较之下，四机构海洋热场项非常接近：完整时段为4.175—4.230，1982年起为4.119—4.167，且区间均完全大于0。由此可见，资料选择主要影响重分配和净变化幅度，对海洋增暖项影响很小。

四机构主口径共同变化项约为−0.479至−0.655，区间均完全小于0；但这仍然只是代数共同变化项，不得因区间排除0而将其解释为物理耦合机制。

## 3. 重分配项为何为负

### 3.1 纬度结构形成最清楚的闭环

主口径的纬度加总显示，路径暴露权重从20°N以南向20°N及其以北移动。1966年起，四机构20°N以北的权重增加5.35—6.50个百分点；1982年起增加1.85—5.48个百分点。所有机构、两个分期方向均一致。

PRIMARY的精确分量加总为：

| 比较 | 纬度区 | 权重变化 | 重分配贡献（`10⁸ J m⁻²`） | 海洋贡献（`10⁸ J m⁻²`） |
| --- | --- | ---: | ---: | ---: |
| 1966年起 | 20°N以南 | −0.0650 | −18.091 | 1.984 |
| 1966年起 | 20°N及以北 | 0.0650 | 11.140 | 2.228 |
| 1982年起 | 20°N以南 | −0.0548 | −15.023 | 2.567 |
| 1982年起 | 20°N及以北 | 0.0548 | 9.699 | 1.578 |

低纬高OHC状态的权重损失大于较高纬度状态的正贡献，因而纬度加总后的重分配项为负。这与主项目已经识别的路径空间北移方向相容，并把“空间重分配”与“海洋热背景暴露”连接起来。但该结果仍是暴露后果，不是北移动力来源。

### 3.2 月份构成不可忽略

由于状态键是“月份×格点”，不能把上述分量简称为纯空间路径项。PRIMARY完整时段的主要负贡献来自10月（−6.320）、11月（−4.321）和7月（−3.670），主要正贡献来自8月（4.866）、9月（4.074）和5月（2.632）。1982年起的主要负贡献转为12月（−4.386）、11月（−3.492）和1月（−2.428），正贡献主要来自9月（2.681）、3月（2.188）和8月（1.956）；单位均为`10⁸ J m⁻²`。

这些月份加总只是既有点估计分量的描述性定位，没有月份级bootstrap区间。它说明季节构成参与了重分配结果，但不能据此单独宣称某个月份发生了显著变化。

### 3.3 经向与纬向变化相互缠绕

PRIMARY完整时段100°—140°E的权重合计增加约0.045，140°—180°E减少约0.045；1982年起对应变化约为±0.041。经度带贡献同样呈现正负抵消，但它与纬度和月份状态共同变化，不能从单一经度带加总中推导独立的东西向机制。纬度结构为路径重分配与热含量暴露之间提供了最清晰的联系。

## 4. 哪些口径最影响结果

以各因素造成的分量变化绝对值中位数衡量，重分配项对以下因素最敏感；单位为`10⁸ J m⁻²`：

| 因素 | 1966年起 | 1982年起 | 含义 |
| --- | ---: | ---: | --- |
| 机构间最大—最小范围 | 3.089 | 4.170 | 最大不确定性来源 |
| 路径定义 | 1.948 | 1.314 | `ts_only`与完整合格路径存在实质差异 |
| 年度权重方式 | 1.907 | 1.188 | 气旋归一与路径点等权不可互换 |
| 海陆处理 | 1.065 | 1.200 | 约3.6%—3.8%的陆上源点足以改变量级 |
| 年份归属 | 0.080 | 0.209 | 两种归年模式差异最小 |

年份键不完全一致对结果的影响小于机构、路径定义和权重口径；后三者是重分配幅度的主要敏感性来源。

净暴露变化对机构及口径更敏感，因为它是方向相反的重分配项、海洋项和共同变化项的代数合计。因此不报告“重分配占总变化比例”，也不以净变化很小时的分量比值解释机制。

## 5. 可以与不可以形成的论文结论

### 可以形成

1. 1966—2025年路径—季节暴露重分配倾向于降低气旋同期OHC300暴露，而海洋增暖倾向于提高暴露；两个方向在全部机构和敏感性口径中一致。
2. 负重分配项的空间基础是暴露权重从20°N以南向更高纬度移动；该纬度结构在四机构和两个起始年份比较中一致。
3. 完整时段的证据强于1982年起时段：PRIMARY完整时段重分配区间不跨0，而1982年起区间跨0。
4. 海洋热场正贡献是最稳定的分量，全部128个区间均大于0。
5. 月份构成对重分配不可忽略，因此应使用“路径—季节重分配”，而不是“纯路径重分配”。

### 不可以形成

1. OHC增暖造成路径北移；
2. 净OHC暴露已经显著下降；
3. 重分配项占总变化的某个稳定比例；
4. 负的共同变化项证明了海洋—路径物理交互或正反馈；
5. 某个月份或经度带已经出现独立显著机制；
6. 单一ORAS5结果完成了完整动力归因。

## 6. 论文价值判断

这项分析形成了“路径变化—海洋背景暴露后果”闭环：北向空间重分配被转换为有量纲的 OHC 暴露贡献，并与海洋增暖贡献在同一恒等分解中比较。该结果量化了路径—季节重分配对同期 OHC300 暴露的影响，不构成 OHC 驱动路径变化的动力归因。

本报告中的数值全部来自 `integration/results/` 中的可追溯 CSV。`integration/figures/` 中的 20°N 南北分区图由 `integration/src/plot_ohc_latitude_contributions.py` 根据同一组 CSV 生成，图件不作为数值读取来源。
