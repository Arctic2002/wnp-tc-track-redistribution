# OHC300 路径暴露方法实现说明

本文件记录已实施的方法设计与验证结果。

| 方法项 | 实现 | 说明 |
| --- | --- | --- |
| `season`/`ohc_year`冲突 | 已统一 | 主口径按`ohc_year`；`season_year_aligned_only`敏感性剔除跨年时次；场值复核使用`ohc_year`。 |
| 两套裁剪实现不兼容 | 已明确输入链 | 本分析直接读取原始ZIP，旧`Verify/ocean_process`不是上游输入。 |
| 陆上点吸附海洋格点 | 已区分 | GSHHG 0.02°标记；主口径排除陆上源点，原口径保留为敏感性并报告数量。 |
| seam阈值 | 稳健统计与人工判读 | 报告稳健z与经验分位数，并结合有效足迹判读，不用任意阈值自动判定。 |
| 有效数据足迹 | 已核对 | 裁切清单和seam诊断记录逐月有限格点数、全年稳定足迹及2014/2015差异。 |
| 非有限状态键 | 明确定位 | 报告前20个`year/month/y/x`并保留完整状态空间。 |
| bootstrap交叉积 | 已验证 | 合成测试与显式重抽比较，使用按场量级缩放的绝对容差。 |
| 空年降级 | 不静默降级 | 在载入全部场之前对每个机构、定义、年份口径和海陆口径做完整覆盖预检，缺年即报告并停止。 |
| 22年样本末块截断 | 已说明 | 方法说明记录循环块生成和末块截断。 |
| KD-tree缓存 | 未使用 | 格点索引按产品载入，不影响科学口径。 |
| xarray版本 | 已记录 | 实际运行环境见`config/environment.yml`；单位属性缺失时程序终止。 |

分析代码、合成测试和真实数据计算均已完成。

## 其他实现说明

| 方法项 | 实现 | 说明 |
| --- | --- | --- |
| 年份模式与主项目season归年不同 | 已说明 | `METHOD_SPEC.md`明确：日历年主口径保留全部点但年份键不同，season对齐敏感性按season归年但删除跨年点；二者不等同于主项目年度样本。 |
| `storms`与跨年权重 | 已区分 | `storms`表示出现片段的唯一气旋数；`annual_exposure.csv`同时给出`effective_storms = Σ_s n_{s,y}/N_s`，后者不是统计有效样本量。 |
| 敏感性专属状态键 | 已登记 | 共同反事实状态空间保持不变；每个状态键登记主口径或敏感性使用标志，非有限值错误同时报告口径归属。 |
| 区域预处理入口 | 已统一 | `Verify/ocean_process`中的旧入口指向本包规范实现；下载器和原始数据清单保持可用。 |
| 闭合容差、xarray attrs、交叉积等价、月份排序 | 已验证 | 现有实现满足对应数值与结构标准。 |

上述实现已纳入分析代码，并通过22项合成测试与1966—2025年真实数据计算。
