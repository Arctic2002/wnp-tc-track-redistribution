# 独立验证标准

独立验证得到以下结论：

1. “月份×原生海洋格点”的状态定义与目标estimand一致，结果命名为“路径—季节重分配”。
2. 同期月OHC只解释为暴露或共变，不表示风暴前环境或因果动力。
3. PRIMARY与USA、JMA、CMA的TS资格、完整路径定义和IFLAG使用与既定口径一致。
4. 球面KD-tree、75 km门限、域外点及有限值海洋格点处理符合方法定义。
5. GSHHG海陆标记、陆上点主排除和最近海洋格点敏感性均按声明口径实现。
6. 日历年主口径和season对齐敏感性明确区分于“保留全部点、按season归年”的路径口径；跨年片段未被当成完整气旋重复赋权。
7. 每气旋归一、每年等权与路径点敏感性均对应声明的estimand。
8. $P+O$精确闭合气候态暴露差，$P+O+\Delta C$精确闭合实际年均暴露差。
9. 3年块抽样同步保留每年的路径权重和OHC场，不制造伪独立样本；交叉积实现与显式重抽等价。
10. 2014/2015 seam记录坐标容差、实际最大坐标差、有效足迹、z值和经验分位数，产品接缝决定为`accept_with_limitations`，未作自动订正。
11. 输出CSV能够追溯全部报告结论。
12. 产品拼接与分解闭合均有数值检查。
13. `storms`与`effective_storms`分别表示片段覆盖计数和跨年权重总量，二者均不表示统计有效样本量。
14. 非有限状态键错误会标明该键属于主海洋点口径、全点敏感性口径，或仅由陆源敏感性点引入。
15. `5×10⁻⁵°`坐标绝对容差只吸收float32量化微差，场矩阵载入与seam诊断使用同一口径。

## 解释边界

- 分期、区域、月份、最大匹配距离、权重和机构不随结果改变。
- USA、JMA和CMA表示跨机构一致性，不表示独立验证。
- `ohc300`不等同于TCHP，同期月场不表示风暴前OHC。
- 有量纲分量和闭合残差与分量方向同时报告。
- 年际共变代数项不命名为物理交互或正反馈。
- 数值结论来自CSV和脚本计算，不从图中读取。
