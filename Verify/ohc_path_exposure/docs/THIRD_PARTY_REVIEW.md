# 第三方审查说明

## 1. 审查材料隔离

每位审查者建立独立目录：

```text
third_party/<reviewer_id>/
├─ SOURCE.md
├─ review.md
├─ code_or_patch/
├─ test_results/
└─ ADJUDICATION.md
```

第三方补丁不得直接覆盖 `src/`。先记录来源、日期、输入文件 SHA-256、软件环境、是否看过预期结果以及代码许可，再逐项裁定。

## 2. 优先审查问题

1. 将状态定义为“月份×原生海洋格点”是否与目标 estimand 一致；“路径—季节重分配”命名是否充分。
2. 同期月 OHC 是否只被解释为暴露/共变，而没有被误写成风暴前环境或因果动力。
3. PRIMARY 与 USA/JMA/CMA 的 TS 资格、完整路径定义和 IFLAG 使用是否与项目既有口径一致。
4. 球面 KD-tree、75 km 门限、域外点及有限值海洋格点处理是否正确。
5. GSHHG 海陆标记是否正确；陆上点主排除和最近海洋格点敏感性是否实现为声明口径。
6. 日历年主口径和 season 对齐敏感性是否充分披露了与主项目“保留全部点、按 season 归年”口径的不完全对应；跨年片段是否没有被当成完整气旋重复赋权。
7. 每气旋归一、每年等权与路径点敏感性是否实现为声明的 estimand。
8. $P+O$ 是否精确闭合气候态暴露差，$P+O+\Delta C$ 是否精确闭合实际年均暴露差。
9. 3 年块抽样是否同步保留每年的路径权重和 OHC 场，且没有制造伪独立样本；交叉积捷径是否与显式重抽等价。
10. 2014/2015 seam 是否报告坐标容差与实际最大坐标差、有效足迹、z 值和经验分位数，并保留人工裁定而不擅自订正。
11. 输出文件是否足以从 CSV 追溯所有候选文字结论。
12. 直接运行任一阶段脚本是否仍会触发代码审查门禁；直接运行分解脚本是否同时触发seam门禁。
13. `storms`与`effective_storms`是否分别表达片段覆盖计数和跨年权重总量，且没有被误称为统计有效样本量。
14. 非有限状态键报错是否标明该键用于主海洋点口径、全点敏感性口径，或仅由陆源敏感性点引入。
15. `5×10⁻⁵°`坐标绝对容差是否只吸收float32量化微差，且场矩阵载入与seam审计使用同一口径。

## 3. 明确不接受

- 根据结果改变分期、区域、月份、最大匹配距离、权重或机构；
- 把 USA/JMA/CMA 写成独立验证；
- 把 `ohc300` 写成 TCHP，或把同期月场写成风暴前 OHC；
- 只报告分量比例而不报告有量纲分量和闭合残差；
- 将年际共变代数项直接命名为物理交互或正反馈；
- 只看图、不核对 CSV 与脚本计算；
- 在来源和裁定未登记时直接合并第三方代码。
