# 2026-08-01 第三方代码审查裁定

来源：`Word/OHC验证包代码审查.md`。本裁定只针对执行前代码包，不表示真实数据结果已经通过。

| 审查项 | 裁定 | 落实方式 |
| --- | --- | --- |
| `season`/`ohc_year`冲突 | 直接采纳 | 主口径统一按`ohc_year`；新增剔除跨年时次的`season_year_aligned_only`敏感性；场值复核改用`ohc_year`。 |
| 两套裁剪实现不兼容 | 暂不合并 | 本包隔离读取原始ZIP，旧`Verify/ocean_process`不是上游输入；待本包复审和调试通过后再决定薄封装。 |
| 陆上点吸附海洋格点 | 直接采纳 | GSHHG 0.02°标记；主口径排除陆上源点，原口径保留为敏感性并报告数量。 |
| seam阈值过松 | 限定采纳 | 不改成另一任意阈值；取消自动PASS，报告稳健z与经验分位数并强制人工裁定。 |
| 有效数据足迹未检查 | 直接采纳 | 裁切清单和seam审计增加逐月有限格点数、全年稳定足迹及2014/2015差异。 |
| 非有限状态键难定位 | 直接采纳诊断部分 | 报告前20个`year/month/y/x`；不自动丢弃状态键。 |
| bootstrap交叉积无等价测试 | 直接采纳 | 增加与显式重抽比较的合成测试，使用按场量级缩放的绝对容差。 |
| 空年降级 | 不静默降级 | 在载入全部场之前对每个机构、定义、年份口径和海陆口径做完整覆盖预检，缺年即报告并停止。 |
| 22年样本末块截断 | 采纳披露 | 在方法说明中写明循环块生成和末块截断。 |
| KD-tree缓存 | 暂缓 | 正确性复审通过后再优化，不与本轮科学口径修复混合。 |
| xarray版本 | 限定采纳 | 首次调试时登记实际环境；当前单位属性缺失会安全失败，不先锁死未经本机验证的版本组合。 |

执行锁继续保持。上述代码仍须第三方复审，不能据此创建正式批准文件。
